ENSO winters

Monthly summary

Data. Open-Meteo Historical Weather API (ERA5 / ERA5-Land reanalysis, 1950 onward), fetched live for the chosen coordinates. It is a gridded model of the location, not a weather station record, so it can run a few degrees off a nearby station, and modeled snowfall is only a rough guide. Winters are November–April; the current winter is excluded until it finishes.

El Niño and La Niña. Winters are classed from NOAA's Oceanic Niño Index (ONI, 3-month Niño 3.4 anomalies): El Niño when October–January readings stay at or above +0.5 and La Niña when they stay at or below −0.5, with strength from the peak reading. The table and the rule are in js/enso.js. NOAA's official episode list uses slightly different rules (and has begun using a relative index, RONI), so a few winters can differ in strength or class. The phase tilts the odds at best: snowfall in any single winter varies a lot.
